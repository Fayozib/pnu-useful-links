# PNU Useful Links 🔗

A curated list of useful websites for **Pusan National University (PNU)** students, especially **international students** and **Computer Science & Engineering** majors living in Busan.

🌐 **Live page:** `https://fayozib.github.io/pnu-useful-links/`

> 🇺🇿 Pusan Milliy Universiteti talabalari (ayniqsa chet ellik va CS&E talabalari) uchun foydali saytlar ro'yxati.
> 🇰🇷 부산대학교 학생(특히 유학생과 정보컴퓨터공학부 학생)을 위한 유용한 사이트 모음입니다.

## 🏫 PNU — University

| Site | What it's for |
|------|---------------|
| [PLATO](https://plato.pusan.ac.kr) | LMS — lectures, assignments, notices |
| [PNU Student Support System](https://onestop.pusan.ac.kr) | Course registration (수강신청), grades, scholarships |
| [PNU CSE Department](https://cse.pusan.ac.kr) | Department notices, scholarships, contests, lab info |
| [PNU Library](https://lib.pusan.ac.kr) | Library search, study room booking |
| [PNU Main Website](https://www.pusan.ac.kr) | University-wide news and announcements |
| [Everytime](https://everytime.kr) | Student community, course reviews, timetable |

## 🤝 Contributing

Know a useful site that's missing? Contributions are welcome!

1. Fork this repository
2. Add the link to `README.md` **and** to the `links` list in `index.html`
3. Open a Pull Request with a short explanation of why it's useful

Please only add sites that are **free to access** and **genuinely useful** for PNU students.
